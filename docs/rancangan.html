BAB 1

Misi: tiga sistem, satu kode

Markas, tengah malam.
Game PS2 ini kita terjemahkan sekali jadi C++, lalu kita kompilasi untuk tiga sistem sekaligus. Bukan emulator!
SENSEI

Nintendo Switch

un5.nro

Atmosphère, AArch64 (Cortex-A57), OpenGL lewat Mesa.

macOS

UN5.app

Apple Silicon, OpenGL 4.1. Sekaligus tempat kerja.

Windows

un5.exe

x86-64, OpenGL 4.x. Build otomatis di GitHub Actions.

Jadi yang beda cuma lapisan tipis platform/: jendela, controller, suara, lokasi file?
MURID
Betul. Kode game dan runtime-nya sama persis di ketiganya. Mac itu ARM seperti Switch, jadi masalah khas ARM ketemu duluan di Mac.

BAB 2

Kenapa bukan emulator?

Di NetherSX2, Switch...
7 FPS!!

Tersendat saat bertarung, anjlok ke 7 FPS waktu save dan cutscene.

Emulator

Menerjemahkan setiap instruksi MIPS saat game jalan, meniru GS dan VU siklus demi siklus.

Recompile

Kodenya sudah jadi AArch64 biasa sebelum game dijalankan. GS digambar langsung dengan GPU.

Langkah 1

func_1FA5D0(id) mengecek overlay yang aktif. Kalau beda, panggil pemuat.

Langkah 2

func_1C3150 membaca cdrom0:\PRG\nama utuh ke alamat tetap. Kode mulai di +0x40.

Langkah 3

func_100270: FlushCache, kosongkan BSS, jalankan constructor.

KETEMU!
Cukup ganti func_100270 dengan versi kita, baca ID di 0x6c6d04, lalu aktifkan tabel fungsi overlay itu. Kode game tidak disentuh sama sekali.

Dicari lewat pasangan NOP khas VU (0x8000033C/0x000002FF) dan 87 penanda akhir program.

5 blok, ~9.000 pasang instruksi. Overlay tidak membawa microcode sendiri.

Berarti semua program VU1 bisa diterjemahkan lebih dulu, seperti di God of War?
MURID
Ya. Dan area ini harus dikeluarkan dari terjemahan kode MIPS. Kalau tidak, recompiler mengira microcode itu instruksi MIPS.

BAB 6

Musuh yang menunggu

Audio

cri_adxi.irx (CRI ADX) dan sndbase.irx butuh libsd di sisi IOP dan mixer SPU2. PS2Recomp upstream belum punya.

Rencana: jalan tanpa suara dulu.

Kecepatan GS dan VU1

Pengembang PS2Recomp sendiri menyebutnya "very bad". CPU Switch cuma 4 core ARM ~1–2 GHz.

Baru bisa diukur setelah boot di Mac.

BAB 8

Sekutu dari desa sebelah

port God of War yang sudah bisa dimainkan

Waffle565

Runtime native: GS di GPU, VU1 dikompilasi, IRX dikompilasi ke C++, mesin suara dari panggilan LIBSD, file disk di sektor aslinya.

TANPA LISENSI

Boleh dipelajari, tidak boleh disalin.

KIexster

Dibangun di atas runtime Waffle. Paling aktif: 188 bintang, tes CI, di-push hari ini.

GPL-3.0

Tobiichi-Port

Membawa fork PS2Recomp dengan 58 file runtime lebih banyak dari upstream.

GPL-3.0
Itu persis musuh di Bab 6! Audio dan GS lambat sudah mereka kalahkan?
MURID
Bagian yang generik, ya: renderer GS OpenGL, VU1 native, sumber disk, perangkat audio, interpreter rujukan PCSX2. File gow_* khusus God of War kita tinggal. PS2Recomp sendiri GPL-3.0, jadi lisensinya sejalan.

SUMPAH

Aturan main

  • Tidak ada file game, kode hasil terjemahan, atau kunci di repository.
  • Yang dirilis cuma alat dan runtime. Setiap pengguna membangun game dari ISO miliknya sendiri.
  • Build lokal maksimal setengah core Mac supaya tidak panas.
  • Kode Waffle565 hanya dipelajari, tidak disalin. Kode GPL-3.0 dipakai dengan lisensi yang sama.
  • Port Naruto Senki (ns-nx) tetap ditunda.
